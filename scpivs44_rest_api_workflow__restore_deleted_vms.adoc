= 使用 SCV 還原已刪除 VM 的 REST API 工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
若要使用SnapCenter VMware vSphere REST API的VMware vCenter外掛程式執行VM備份還原作業、您必須遵循規定的REST API呼叫順序。

針對每個REST API、請新增 `\https://<server>:<port>` 在REST API的前面、形成完整的端點。

|===
| 步驟 | REST API | 註解 


| 1. | 前往 `\http://<vCenter-IP>/mob` | 從 VMware 管理物件 URL 中找到資料儲存 *moref*。記下已刪除 VM 所在的資料儲存的 moref。 


| 2. | `/4.1/datastores/{moref}/backups` | `Get Datastore Backups` 擷取指定資料儲存區的備份清單。傳遞步驟 1 中的 *moref*。記下您要還原之備份的 *backupId*。 


| 3. | `/4.1/backups/{backupId}` | `Get Backup Details` 檢索指定備份的詳細資訊。傳遞步驟 2 中的 *backupId*。在實體清單中，找到與已刪除 VM 相符的 *entityName*，並附註 *UUID*。 


| 4. | `/4.1/vm/backups/{backupId}/snapshotlocations` | `Get snapshot locations` 擷取指定備份的快照位置。傳遞步驟 2 中的 *backupId*。記下 *snapshotLocationsList* 資訊。 


| 5. | `/4.1/datastores/{moref}/availableEsxHosts` | `Get available ESX Hosts` 檢索儲存備份的主機資訊。傳遞步驟 1 中的 *moref*。附註 *availableEsxHostsList* 資訊。 


| 6. | `/4.1/vm/{uuid}/backups/{backupId}/restoreVm` | `Restore a VM from a backup` 還原指定的備份。傳遞步驟 3 中的 *UUID*。傳遞步驟 2 中的 *backupId*。在 *restoreLocations* 屬性中，傳遞步驟 4 中 *snapshotLocationsList* 的資訊；在 *esxHost* 屬性中，傳遞步驟 5 中 *availableEsxHostsList* 的資訊。如果 VM 備份是部分備份，請將 `restartVM`參數設為 *false*。*附註：* 您無法還原做為範本的 VM。 
|===

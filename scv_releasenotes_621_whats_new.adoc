= SnapCenter Plug-in for VMware vSphere 6.2.1 新增功能
:allow-uri-read: 


[role="lead"]
SnapCenter Plug-in for VMware vSphere 6.2.1 是一個維護版本。它更新了應用裝置附帶的第三方軟體，並修復了自 SnapCenter Plug-in for VMware vSphere 6.2 版本以來發現的問題。



[[updated-components]]
== 更新元件

|===
| 元件 | SnapCenter Plug-in for VMware vSphere 6.2.1 


| Java 執行時期環境 | OpenJDK 21.0.12 


| .NET 執行階段 | .NET 10.0.11 


| 應用裝置作業系統 | Debian 13 
|===


[[fixed-issues]]
== 已修復問題

在升級到新版本之前，最好審查版本中修復的已知問題。

|===
| 錯誤 ID | 說明 


| VMDP-7072 | 可以將 Oracle Cloud 上的雲端管理 ONTAP 新增為儲存系統。 


| VMDP-7052 | 將 VM 還原到不同的位置會保留 VM 的儲存設備原則，因此對於使用非預設原則的 VM，還原不再被拒絕。 


| VMDP-7027 | 支援日誌包包含已配置儲存系統的清單。 


| VMDP-6987 | 附加或還原虛擬磁碟時，即使 vCenter 短暫報告資料儲存不可用，也不會再出現失敗的情況。 


| VMDP-6965 | 當某個排程記錄不完整時，排程頁面不再無法載入。 


| VMDP-6952 | 當使用者沒有刪除資源群組的權限時，就會顯示權限訊息。 


| VMDP-6939 | 維護主控台不再報告缺少 VMware Tools。 


| VMDP-6935 | 瀏覽備份以還原單一檔案的功能不再失效。 


| VMDP-6933 | 新應用裝置部署在首次設定期間不再無法完成。 


| VMDP-6931 | 輔助備份的清理工作不再因為某個 Volume 無法存取而等待數小時。其他 Volume 的處理工作會繼續進行。 


| VMDP-6817 | 重新命名來源 ONTAP Volume 後，輔助備份不再會停留在舊名稱，也不會顯示不再有效的項目。 
|===
